**[async-wrapper-devsecops-showcase](https://github.com/theonix-dev/async-wrapper-devsecops-showcase)** is an async Python wrapper with DevSecOps automation around it:

- Zero-trust ACL middleware and RBAC
- Multi-service Docker orchestration on an isolated bridge network
- Prometheus metrics and Sentry exception monitoring
- Redis caching with automatic local-file failover
- Secrets kept out of code through typed `.env` configuration
